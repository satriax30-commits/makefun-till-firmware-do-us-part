Entry for the make.fun bounty **Till Firmware Do Us Part**: a tiny
deterministic Node 22 program (`main.ts`, stdlib only, no network, no
wall-clock, no randomness) that writes one original one-line wedding vow a
robot speaks at its own wedding to `/output/entry.txt`, with a 1–200
character gate validation, a one-sentence check, and a read-back self-check.

Run it:

```sh
node main.ts [output-dir]
```

With no argument it writes to `/output/entry.txt`.
